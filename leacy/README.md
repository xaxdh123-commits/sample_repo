# 样品标签系统

这是一个轻量的局域网页面系统，用于排版人员录入样品、打印热敏标签，公司其他同事可以免登录查询样品库。

## 启动

1. 安装 Node.js 18 或以上版本。
2. 双击 `start.bat`，或在本目录运行：

```powershell
npm start
```

主页面：

```text
http://localhost:8080
```

同事在局域网其他电脑访问时，把 `localhost` 换成运行这台电脑的 IP，例如：

```text
http://192.168.1.100:8080
```

## 账号和游客

- 默认进入“样品库查询”，游客无需账号，只能查询和查看。
- 点击“录入打印”会弹出账号登录。
- 默认管理员账号：`admin`
- 默认管理员密码：`admin`
- 管理员可以在“账号管理”里新增编辑账号、停用账号、重置密码。
- 编辑账号可以录入样品、店铺、打印标签、补打、作废、维护店铺负责人、导出备份。

## 默认设置

- 起始编号：`0001`
- 编号规则：`0001` 到 `9999` 为四位数，超过后自动显示 `10000`、`10001`
- 作废编号不占号，系统会按有效记录自动补回最小缺号
- 标签尺寸：`60mm x 40mm`
- 数据文件：`data/samples.json`

## 备份和恢复

在“录入打印”页面下方可以导出备份。管理员还可以导入备份。

备份文件包含样品记录、图片、店铺负责人、账号信息和下一个编号，建议每天或每周保存到 U 盘、NAS 或公司共享盘。导入备份会覆盖当前样品库，系统会先在 `data/` 目录自动保留一份当前数据副本。

## 使用流程

1. 排版人员登录账号，填写版号、客户名、店铺、店铺负责人。
2. 如有需要，上传或粘贴一张样品图片，系统会自动压缩成可查看的缩略图。
3. 点击“保存并打印”。
4. 系统自动生成样品编号，并打印标签。
5. 标签贴到信封袋上，后端使用完按编号顺序存放。
6. 如果打错，点“作废”，这个编号会回到下一个可用编号里。
7. 后续反单时，在“样品库查询”按版号、客户名、店铺、编号、店铺负责人或号码检索。

## 热敏打印机建议

在“录入打印”页面可设置热敏纸宽高，系统会记住上次规格。浏览器打印窗口中也要选择相同纸张尺寸，边距设置为无或最小。

## 自动备份规则

系统启动后会自动做每日备份，并且每小时检查一次是否跨天。自动备份保存在 `data/backups/日期文件夹/`，例如 `data/backups/20260618/backup-before-20260618.json`。

- 2026-06-18 会建立 `20260618` 文件夹，备份 2026-06-18 之前的样品记录。
- 2026-06-19 会建立 `20260619` 文件夹，备份 2026-06-19 之前的样品记录。
- 2026-06-20 会建立 `20260620` 文件夹，备份 2026-06-20 之前的样品记录。

每日自动备份里的样品记录按日期截取；店铺负责人和账号信息会完整保存，方便后续恢复。
系统只保留最近 7 个日期文件夹的自动备份。第 8 天生成新备份后，会自动删除最旧的日期文件夹，循环替换，避免数据越存越多。
